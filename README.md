# C ↔ Rust Geçiş Rehberi

C ve Rust **farkları**, idiomatik dönüşümler ve **FFI / migration** yolları.
Kardeş başvurularla birlikte okuyun.

## Kardeş kitaplar

- [c-basvuru](https://github.com/mfguney/c-basvuru) — C başvurusu
- [rust-basvuru](https://github.com/mfguney/rust-basvuru) — Rust başvurusu

## Yerel önizleme

```bash
cargo install mdbook
mdbook serve
```

## GitHub Pages

Pages kaynağı: **GitHub Actions**. URL ve repo adlarını `book.toml` / README’de güncelleyin.
